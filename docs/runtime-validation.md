# 실제 모델 및 카메라 검증

2026-10-21, 로컬 RTX 3050 4GB Laptop GPU에서 실행했습니다.
원시 측정값은 [runtime-validation.json](runtime-validation.json)에 있습니다.

## 조건

- PyTorch 2.9.1+cu128, Ultralytics 8.4.182, `device=0`
- 객체: 로컬 `yolov8n.pt`. 기본 설정인 `yolo26n.pt`는 로컬에 없어 검증하지 않았습니다.
- 사람 키포인트: `yolo26n-pose.pt`, 깊이: `yolo26n-depth.pt`
- 외부 다운로드와 의존성 자동 설치를 끈 상태로 실행했습니다.
- 샘플은 설치된 Ultralytics의 `bus.jpg`, `zidane.jpg`이며, 각 영상을 한 번 실행한 뒤 10회 측정했습니다.

| 회귀 검사 | pytest 91개 통과, Ruff/포맷/diff 검사 통과 |

API의 백엔드 전송은 기록용 대체 함수로 확인했습니다. 실제 백엔드에는
검출 결과를 전송하지 않았습니다. 카메라 이미지는 저장하거나 외부로 전송하지 않았습니다.
카메라 FPS는 캡처·추론·그리기·JPEG 변환을 포함한 짧은 구간의 관측값입니다.
10회 표본에서 최근접 순위로 계산한 p95는 표본 최댓값이며 장기 부하 수치가 아닙니다.
API는 TestClient로 호출했으므로 네트워크 전송 지연을 포함하지 않습니다.

## 검증 중 수정

기존 예열은 빈 프레임에서 사람이 없으면 깊이 추론을 건너뛰었습니다.
`FaceDistanceDetector.warmup()`이 pose 추론과 깊이 추론까지 실행하도록 수정하고,
사람이 없는 경우에도 깊이 예열이 실행되는 회귀 테스트를 추가했습니다.
샘플 추론 표는 이 수정 전 측정이고, API와 연속 카메라 검증은 수정 후 실행했습니다.
입력 종횡비가 달라지면 초기 장치 설정 때문에 첫 요청 지연이 여전히 길 수 있습니다.

## 확인하지 못한 항목

실제 CUDA 메모리 부족을 발생시키지 않았습니다. 오류 주입으로 전환 경로를 실행하되
CPU·GPU에서 실제 깊이 모델을 사용했습니다. 정답 라벨과 실측 거리가 없어
정밀도·재현율·거리 MAE는 측정하지 않았습니다. 이 값들은 드론 촬영 데이터와
실측 거리 라벨로 `tools/evaluate.py`를 실행해야 확인할 수 있습니다.
